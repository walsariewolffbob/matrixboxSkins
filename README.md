# MatrixBoxSkin Repository

This repository contains skins for the RevampedDepartures app.

All skins uploaded here are functional, though check the minimum required version of RevampedDepartures listed in a skins `skin.json` file before uploading, as some skins might require changes to the core before they are functional. 

In `manifest.py` you can also see which screen sizes are supported, and if the skin is optimised for that specific version.

*An app for MatrixBox which will upload skins directly is currently under development.*

> NB: These skins work with the RevampedDepartures app only. Not the current official Departures app.
